# Code of Conduct

Boxdeck has adopted the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who takes part in the project, in issues, pull requests, discussions or any other project space, is expected to follow it.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the maintainers through the contact listed on the [oops-apps GitHub profile](https://github.com/oops-apps). Reports are handled confidentially.

Maintainers who don't follow the code of conduct in good faith may face temporary or permanent consequences, as determined by the other members of the project's leadership.
