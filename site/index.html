FAQ

Questions, answered

Is there a GUI for Vagrant?

Yes. Boxdeck is a free, open-source desktop GUI for HashiCorp Vagrant on macOS, Windows and Linux. It lists every Vagrant machine on your computer and lets you start, stop, provision and SSH into them from a window or the menu bar.

Does Boxdeck replace the vagrant command?

No. Boxdeck runs the vagrant you already have installed (2.3 or newer), so your Vagrantfiles and terminal workflow keep working exactly as before.

Which Vagrant providers does it support?

Any provider Vagrant supports, including VMware Desktop, VirtualBox, Docker, Hyper-V and libvirt. It is tested with VMware Desktop (VMware Fusion) and Docker.

Can AI agents manage Vagrant machines with Boxdeck?

Yes. Boxdeck includes an MCP server that is off by default. You choose Read, Operate or Full access per client, destructive actions need your approval, and every call is written to an audit log.

Is Boxdeck free?

Yes. Boxdeck is free and open source under the MIT license.

Is Boxdeck made by HashiCorp?

No. Boxdeck is an independent open-source project and is not affiliated with or endorsed by HashiCorp. It ships none of Vagrant's code.

Up and running in a minute

If you already use Vagrant, there is nothing to set up.

01

Have Vagrant installed

Vagrant 2.3 or newer and a provider. Starting fresh? Follow the install guide.

02

Install Boxdeck

Grab the installer from Releases once v0.1.0 is out, or build it from source.

03

Open it

Every machine Vagrant knows about shows up. Add other folders with Add project…

# build from source $ git clone https://github.com/oops-apps/boxdeck && cd boxdeck $ make install $ make build
